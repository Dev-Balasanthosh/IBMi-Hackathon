🧠 6 Bob Skills — .bob/skills/

🔌

Connection Resolver

connection-resolver/SKILL.md

TCP probe to PUB400. Sets 🟢 LIVE or 🟡 FALLBACK mode for the session.

📚

Library List Resolver

library-list-resolver/SKILL.md

Resolves effective library list. Validates scope. Prevents false "not found" conclusions.

🔍

Object Discovery

object-discovery/SKILL.md

Finds IBM i objects via QSYS2. Handles single match, multiple libraries, and not-found.

📄

Source Locator

source-locator/SKILL.md

Finds source file, library & member. Gracefully handles missing source with explanations.

🔗

Dependency Analyzer

dependency-analyzer/SKILL.md

Outbound refs via DSPPGMREF / QSYS2. Attempts inbound analysis with honest fallback.

🧠

Explanation Orchestrator ⭐

explanation-orchestrator/SKILL.md

Primary demo skill. Self-contained 6-step workflow inline. Calls MCP tools directly. Full result card + trace.
